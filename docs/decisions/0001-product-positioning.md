# 0001 产品定位：服务商家的知识与回答层

日期：2026-10-15　状态：已采纳

## 背景

前期开发在 Medusa 集成、公开数据双轨、实时订单工具和证据边界验收之间反复调整，缺少"为谁做、做什么"的统一判据。项目方没有自己的电商平台。

## 决定

- 做开源、可自部署的电商客服知识引擎，作为电商平台旁边的知识与回答层，不自建或深度对接电商平台。
- 首版服务国内平台（淘宝、抖店、拼多多）的中小商家，入口是**客服辅助模式**：工作台给出带出处的建议回复，由客服复制回平台发送。界面和资料全中文。
- 网页挂件和开放 API 放到 P4。
- 范围细节见 [产品定位](../product.md)。

## 后果

- 不依赖平台开放接口或服务商资质，就能让真实商家用起来。
- Medusa、公开数据集、实时订单和库存进入暂缓清单，已有代码和审计保留，但不再投入。
- 价值通过真实商家问题上的自动解答率和错答率来证明，而不是内部验收报告。
