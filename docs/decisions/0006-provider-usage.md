# 0006 开发期真实模型的使用方式

日期：2026-10-16　状态：已采纳

## 背景

调提示词、检索和解析时，离线 mock 反映不了真实效果。但真实模型（阿里云百炼）按调用计费，需要把费用控制住。

## 决定

- 开发和调试时可以按需调用真实模型，不必为每次调用单独申请授权。
- 所有真实调用（ai、worker、评测、smoke）共用同一个预算账本，不为绕过额度而新建账本。
- 账本窗口的上限由用户决定。额度用完或接近用完时停下来，向用户申请扩额，不自行扩额。
- 每个里程碑结束时，用真实模型跑一次冻结评测，并与基线对比。
- 默认回归（`bash scripts/check.sh`）始终使用离线 mock，不产生费用。

## 后果

- 账本位于仓库外（见 [开发指南](../development.md)）。开发前确认运行配置中的 `V2_ONLINE_BUDGET_*` 指向这个账本。
- 原有规则"每次付费调用都需要授权"由本条取代；[AGENTS.md](../../AGENTS.md#安全) 中的相应表述同步更新。
