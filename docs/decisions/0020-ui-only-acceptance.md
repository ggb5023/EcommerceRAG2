# 0020 仅 WebUI 商家验收

- 状态：已采纳
- 日期：2026-10-27

## 决定

商家部署完成后，A 级日常功能必须能只通过 WebUI 完成；B 级部署运维允许 CLI 但须一条命令；
C 级开发评测不属商家范围。

完整矩阵、31 条 admin 路由的 UI 承载、操作成本列与缺口清单见
[仅 WebUI 验收标准](../ui-only-acceptance.md)。

## 操作成本口径

矩阵中的“单条 / 批量 / 一键”决定后续优先级：只有“单条”的行，L2 或对应批量能力是它的前置。
知识导入与批量导入向导为一键；审核发布、批次撤回、权限审批目前为单条，L2/批量能力落地前如实保留。

## 后果

A 级缺口补齐后，本条作为 WebUI-only 验收依据；模型供应商选择（0019）仍属 P3，单独验收。
