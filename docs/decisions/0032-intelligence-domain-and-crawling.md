## 2. 两个域

```text
answer 域        自有内容 + 已授权来源 → 可被顾客引用
intelligence 域  外部抓取的情报       → 仅内部可见，永不进对客回答
```

- 域标记**随 scope 经 gRPC 下发**（与 `allowed_document_ids` 同一通道，`proto/rag/v1/rag.proto:16`），
  因此是**跨进程契约**：`docs/contracts.md` 需新增一行「scope 域标记」，Go 侧签发 +
  Python 侧校验，两侧各有一个测试，状态才允许 ✅。
- 域判定由宿主决定，数据源与插件只能申报，不能自决。

## 3. 共享层与租户层（最关键，两层 + 角色级隔离）

情报数据天然跨租户：一份竞品价格服务所有商家。因此分两层，**且共享层用独立数据库角色强制隔离**：

```text
共享层（market）   键：market / 类目 / 平台 + 观测时间
                   无 tenant_id；所有商家只读；写入方是系统抓取 worker
租户层（tenant）   键：tenant_id
                   商家自己的目标清单、监控配置、告警记录
```

规则：

- 共享层只写一次，由系统抓取任务维护，商家不可写；
- 租户层只存「商家想看什么」，不复制共享数据；
- **共享层使用独立 DB 角色 `rag_v2_intel`**，共享层表只授权给该角色，
  answer 侧角色（`rag_v2_ai` / `rag_v2_ingest` / `rag_v2_gateway`）物理读不到——
  「intelligence 永不进 answer」在数据库权限层强制，不只靠应用层域过滤。
- 共享层与抓取 worker 是**新写者域 + 新表**：实现前先在 `docs/data-ownership.md` 登记
  表与写者，再写迁移并 GRANT（同 environment-facts #4 的教训）。
- 共享层数据进入 answer 域的唯一途径是**商家显式导入成自己的资料**（走现有
  导入→审核→发布），不自动流动。

## 4. 抓取能力清单

### 客服视角（answer 域，全部仍走导入→审核→发布）

| 能力 | 抓什么 | 说明 |
| --- | --- | --- |
| 知识库冷启动 | 商家自有站点 | 导入→审核→发布 |
| 内容保鲜 | 已发布页面的新版本 | 变更检测 |
| 缺口反向验证 | 商家站点 | 「该补哪个页面」 |
| 平台规则库 | 平台退换/发货/资质规则 | **抓取产物是「导入候选」，仍须商家确认后走审核发布，不直接进 answer** |
| 时效信息 | 物流/发货说明页 | 同上，带观测时间 |
| 话术语料 | 评价、历史对话 | 仅内部语料，不对外引用 |

> 注：§3 的「共享→answer 只能显式导入」与本节不冲突——本节所有 answer 域来源，
> 无论是否抓取，一律落回「导入候选 → 审核 → 发布」这条既有管线。

### 商家视角（intelligence 域，等共享层建好再谈）

竞品定价监控、选品需求发现、评论与 VOC、库存供需、渠道分销监控、流量投放情报、
自身站点体检（自己页面归租户层）。这些**全部落在共享层（除自身站点体检）**，优先三队。

**优先级**：

```text
第一梯队  answer 域：自有站点导入 · 变更检测 · 缺口反向验证（不新增域/共享层）
第二梯队  answer 域：平台规则库 · 时效信息（仍走导入审核）
第三梯队  intelligence 域：其余全部（等共享层 + rag_v2_intel 角色建好）
```

## 6. 五条实现原则

1. **抓取复用 ingest 的 schema 与租约语义**（job/fencing/重试/审计的数据面），
   **但跑在独立 worker/进程**（进程面），与回答 RPC 资源池隔离，并有独立限流。
   「复用」指数据面，「隔离」指进程面，二者不矛盾。
2. **数值问题双路**：向量负责「谁」，SQL 负责「多少」。禁止向量直接答数值。
3. **情报必须带时间**：`observed_at` 必填，输出显示「截至 X 时」。
4. **抓取不得与回答同资源池**：`ai_process` 目前同跑 RPC 与 ingest worker
   （`v2_services.py:4`）。情报面开工前，抓取必须有独立进程或硬限流隔离。
5. **抓取必须可配置出口**：默认不允许从商家主服直接抓第三方站点（IP 被封会连带
   影响他自己的客服）。至少支持代理出口，默认关闭。

## 一句话

**难的不是「抓什么」，是「抓来的东西归谁」。** 现有表按租户隔离，情报天生跨租户——
这条裂缝用「共享层 + rag_v2_intel 角色」补上，顺序就是：先定共享层，再谈能力。
