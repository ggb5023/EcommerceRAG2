# 导入与发布店铺知识

[项目入口](../README.md) · [安装](install.md)

管理员进入“资料来源”，选择店铺和来源标识，直接上传 DOCX、Markdown、CSV。总大小至多 8 MiB，最多 100 个文件。首版不支持 PDF、XLSX、OCR 或网页抓取。文件名必须唯一；同一来源内修改同名文件产生同一资料的新版本。改变文件名会建立新的资料标识。

FAQ 表单填写稳定标识、问题、答案；保持标识不变即可更新版本。CSV 模板使用 `question,answer` 两列，逗号、换行或双引号按标准 CSV 引号规则转义。模板入口在上传表单；数据在服务端按实际行解析，不能只上传标题。

上传只提交资料，不等于发布。依次检查：摄取任务的解析和 Embedding 状态 → 版本预览的实际片段 → 审核结论和披露分类 → 发布。初始分类为 `unclassified`，客户看不到。允许对外使用的资料必须审核为 `external_allowed` 并发布；租户、来源或文档 ACL 存在时，还需显式允许 `customer` 角色读取。员工内部资料不能通过客户页面引用。

新摄取版本保留来源位置：Markdown 行范围、CSV 数据记录号及物理行范围、DOCX 文档块和表格编号。字符范围是“解析元素内偏移”，不是原文件偏移；DOCX 不提供页码。旧版本缺少位置时显示不可用，需要完整位置可重新提交新版本，不回填历史数据。审核接口只提供获准的结构信息，不返回任意内部元数据；普通处理提示不会自动阻止发布，仍以原有质量门控和审核决定为准。

版本审核页可按块类型筛选，每段展示至多 12 个片段，表格结构单独展开。店铺设置、资料来源和版本审核提供“以客户身份试问”，打开配置的正常客户页面；不会继承员工权限或检索草稿。没有客户可见知识时先审核发布并核对 ACL。试问会产生正常咨询记录、模型费用及人工排队。

审批、发布、撤销和回退都走真实控制命令。失败看服务端状态并重新对账，不用 SQL 补写终态。FAQ 不从人工客服回复自动生成。首版没有完整草稿协作系统。

同一份资料换来源（例如从旧系统迁到新系统）重传时，请使用**新的文档标识**：标识一旦属于某个来源，就不会转给别的来源；沿用旧标识会得到 409 并提示改用新标识。

客户答案只引用当前有效、符合范围、时效和披露约束的片段。查看来源返回标题、版本和支持片段，不下载原件、不暴露存储路径。撤销、回退或收紧权限后，旧答案和 SSE 回放重新核验；失去依据的客户答案会被隐藏并提示来源撤回。

店铺政策、FAQ、商品说明适合知识库。静态资料不能用来证明当前价格、库存、订单状态或到货日期。上传者负责资料使用授权、个人信息处理及生效日期。
