# Publication records

GitHub preserves the complete publication branch ancestry, source, synthetic
inputs and public usage documentation. Detailed documents, research, historical
reports, original answer captures, evidence and reviews are archived privately
in OSS after inspection. Nonsecret text originals remain unchanged; redacted
copies carry separate original/export hashes and transformation records.

`manifest.json` is generated by `scripts/publication_index.py` from actual files
and originals. It covers the reviewed public fixtures, aggregate historical
reports and archive index in this directory. The private OSS manifest records
all inventoried paths, destinations, hashes, redactions and pending reasons.
Public and private manifests are bound by the archive index and final receipt.
Neither contains signed URLs or credentials.

Historical PASS reports retain their original scope. The original answer-point
gate remains **NOT_PASSED (44/53)**. Latest semantic failures **syn-019 and
syn-031** still require an online rerun. `real_service_acceptance=false`.
Publication is independent of product quality and production acceptance.

See [publication instructions](../docs/publication.md) for verification,
private downloads and pending-material handling.
